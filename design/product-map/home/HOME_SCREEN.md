# Open Consulting — первый экран

5 октября 2026. Один макет для обсуждения; не утверждённый дизайн. Просмотр: `http://127.0.0.1:4182/home/`.

## Задача и композиция

Кандидат из Казахстана должен понять направление «работа в отелях Турции» и выбрать поиск вакансии или создание анкеты. Работодателю доступен отдельный вход в шапке. Фотография показывает работу сотрудников ресепшен, а не отпуск или абстрактную деловую встречу.

Наиболее заметное действие — «Найти работу». Ниже, в том же первом экране, — «Создать анкету» с объяснением видеопрезентации. Полей для телефона, согласий, статистики и карточек вымышленных вакансий на главной нет.

Фирменные цвета: красный `#ec2a20`, тёмный `#1e2024`, светлый фон `#f5f6f7`, белый. IBM Plex Sans, локальный файл с лицензией OFL и проверенными казахскими/турецкими буквами. Оригинальный логотип показан из копии белой версии; кадрирование SVG не меняет исходный PNG.

## Применение референсов

- [HH](https://shymkent.hh.kz/): роли и компактные действия в шапке, рабочая фотография, заметное главное действие. Региональная версия просмотрена через браузер 5 октября 2026. Её главная сейчас сначала предлагает начать резюме, а поиск расположен ниже. Мы адаптировали иерархию под обсуждаемый сценарий поиска.
- [Enbek](https://www.enbek.kz/ru): понятное разделение соискателя и работодателя и большая поисковая форма. Его показатели, государственные услуги и экосистема не относятся к Open Consulting и не перенесены.
- Компоненты действительно импортированы из Radix Themes 3.3.0: Button, IconButton, TextField, Select, DropdownMenu и Dialog. Lucide используется для функциональных иконок. Это общие контролы; композиция подготовлена под продукт. Источники и лицензии: [COMPONENT_SOURCES.md](../visual-direction/COMPONENT_SOURCES.md).

## Объём этого шага

Только первый экран, с адаптацией для телефона. Поиск показывает демонстрационное окно без реальной базы; остальные действия объясняют следующий экран. Меню и выбор города используют готовые контролы. Переводы и авторизация не подключены. Реальную видеопрезентацию здесь не изображаем работающей.

Правила доступа гостя к вакансиям ещё требуют уточнения по [ТЗ](../../../TZ_OPEN_CONSULTING_V1_1.md). Видео остаётся обязательной частью анкеты по текущему ТЗ. Остальные страницы не реализованы в этом шаге.

Исходники: `design/visual-direction-src/src/home.jsx` и `home.css`; сборка `npm run build`. Сборка завершилась успешно, автоматические тесты не запускались. Предыдущие макеты сохранены и не считаются принятыми.
