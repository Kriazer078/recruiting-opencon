## Объём

Каждое направление — целая главная, а не только первый экран: шапка с меню ТЗ, первый экран с поиском, блоки ниже по своей модели подачи, новости, отдельный рекламный слот, партнёрам, подвал. Кабинеты, регистрация, запись видео, реальные вакансии и сервер не реализованы. Действия, ведущие к непостроенным экранам, открывают окно «следующий шаг» с описанием по сценарию ТЗ; данные не собираются.

## Код

- Точка входа `design/visual-direction-src/concepts.html`, исходники `src/concepts/` (TypeScript, React 19, Vite 8).
- `portal/`, `guide/`, `scenes/` — по компоненту и файлу стилей на направление. Токены каждого направления объявлены на `:root[data-direction="…"]`; общие только шрифт, сброс, служебная полоса и окно следующего шага (`shared/base.css`).
- Данные переиспользуются из главной v1: `homepage/data/rules.ts` (числа ТЗ), `vacancies.ts`, `content.ts` (меню, новости), `questions.ts`. Описания следующих шагов вынесены в `homepage/data/flows.ts` и общие для v1 и направлений.
- Поведение — примитивы `radix-ui` (ToggleGroup, Dialog, Accordion), иконки Lucide. Новых зависимостей нет.
- Сборка: `npm run check` (typecheck + build) собирает и главную, и направления в `design/product-map/home`.

## Проверено

- `npm run check`: typecheck и сборка без ошибок.
- Ширины 390, 768, 1280, 1440 для всех трёх направлений: горизонтальной прокрутки нет, ошибок консоли нет. Режим отеля — 1440.
- Сценарии кликами в Chromium (Playwright): поиск и быстрые профессии фильтруют ленту, фильтры условий, пустой результат и сброс («Биржа»); выбор роли в строке поиска, результаты под формой, отметки списка «что понадобится», переключение маршрута кандидата/отеля и синхронизация с ролью, подсветка текущего шага при прокрутке, вопросы-ответы («Сопровождение»); поиск выделяет профессию в ленте, переключение вопросов в кадре, смена роли меняет тексты («Лица»); меню телефона содержит 7 пунктов ТЗ и переключает роль; окно следующего шага закрывается по Escape.
- Программная прокрутка учитывает `prefers-reduced-motion`.

Не проверено: экранные дикторы, реальные устройства, Safari и Firefox, вид трёх CDN-фото в «Лицах».
