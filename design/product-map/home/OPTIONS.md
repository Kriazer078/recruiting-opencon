# Сравнение шапки и входа в анкету

5 октября 2026. Новые варианты для обсуждения, пользователь их ещё не выбрал.

Запрос: шапка и нижний блок «Создать анкету» сливаются с тёмным первым экраном; показать разные решения именно этих частей. Продолжаем маленькими шагами. Состав первого экрана, фото и поисковый сценарий сохранены. Разные оформления не означают три новых сайта.

Просмотр и переключение: `http://127.0.0.1:4182/home/?compare=1`. Панель сравнения служит оценке макета, не является интерфейсом будущего продукта. Прямой просмотр без панели: `?variant=1`, `?variant=2`, `?variant=3`. Исходный вид по-прежнему доступен на `/home/` без параметров.

| Вариант | Шапка | Анкета | Смысл и ограничение |
|---|---|---|---|
| 1. Светлые блоки | Белая полоса, тёмный текст, оригинальная геометрия логотипа | Отдельный белый блок через отступ, красная кнопка | Самое явное разделение навигации, поиска и второго действия. Две красные кнопки имеют разную визуальную величину: поиск крупнее |
| 2. Компактная навигация | Самостоятельная белая панель, два пути через готовый переключатель | Белый блок немного перекрывает нижний край фото, тёмная кнопка | Компактность и видимая роль. Перекрытие остаётся, но светлая поверхность имеет явную границу; может быть менее подходящим, если пользователь хочет полностью раздельные части |
| 3. Красный акцент | Тёмная шапка с увеличенным расстоянием до обложки | Самостоятельная фирменная красная полоса, белая кнопка | Самый выразительный вход в видеоанкету. Красная полоса сильнее конкурирует с поиском |

Рекомендация для обсуждения: вариант 1, потому что он прямо решает замечание о слиянии, сохраняя поиск главным действием. Это оценка дизайнера, не согласование пользователя.

Логотип: исходный белый PNG остаётся без изменения. На светлой шапке только белые буквы показываются чёрными через SVG clipPath и CSS brightness; красный знак остаётся из исходного изображения без фильтра. Форма и расположение оригинальных букв сохраняются. Исходные файлы логотипов не редактируются.

Реально используются прежние готовые Radix Themes: Button, TextField, Select, Dialog, DropdownMenu; в сравнении и варианте 2 — SegmentedControl. Источники и лицензии: [COMPONENT_SOURCES.md](../visual-direction/COMPONENT_SOURCES.md). Новые библиотеки ради вариантов не добавлены.

Фото и продуктовые ограничения: [HOME_SCREEN.md](./HOME_SCREEN.md). Вход, вакансии и запись видео остаются демонстрационными. Информация о людях на фото не представляется данными настоящих кандидатов.

Активные исходники: `design/visual-direction-src/src/home.jsx`, `home.css`, `home-options.css`. Сборка `npm run build`; автоматические тесты не запускались. Следующий шаг — выбор шапки и оформления блока анкеты пользователем; их можно сочетать отдельно.
