## Готовые элементы и их задачи

| Radix Themes | Где применяется |
| --- | --- |
| Theme | Общие цвета, радиусы и типографика |
| Button, IconButton | Основные/вторичные действия, мобильное меню |
| TextField | Поиск и поля формы |
| Select | Язык, город, стаж |
| Tabs | Разделы визуального образца |
| SegmentedControl | Компьютер / телефон |
| Dialog | Объяснение демонстрационных действий; штатные фокус и закрытие |
| Checkbox | Поле формы опыта |
| Progress | Пример заполнения анкеты |
| Badge | Подписанные статусы документов |
| Table | Документы и их состояния |

Контролы импортируются из библиотеки. Композиция страницы, тексты, фото, фирменные токены и области содержимого подготовлены для этого проекта. Библиотека не заменяет продуктовую проработку и не делает весь сайт готовым автоматически.

## Правило дальнейшего выбора

1. Сначала определить задачу элемента и роль пользователя.
2. Проверить официальную документацию или автора, актуальность, зависимости и лицензию.
3. Использовать один совместимый набор контролов. Сторонний блок добавлять, когда он даёт подходящее решение конкретного UX.
4. Сохранять штатную семантику, клавиатурное управление и фокус; адаптировать цвет, размер и плотность.
5. Не переносить вместе с шаблоном выдуманные метрики, бесполезные графики, отзывы или обещания функций, которых нет в ТЗ.
