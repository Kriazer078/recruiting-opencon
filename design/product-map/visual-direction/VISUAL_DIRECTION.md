# Open Consulting — визуальное направление 0.1

Дата: 5 октября 2026. Этап 2. **Образец для обсуждения, оформление ещё не утверждено.**

Основа продукта: [ТЗ OC-TZ-JOBS-001 v1.1](../../../TZ_OPEN_CONSULTING_V1_1.md). Более поздние указания пользователя имеют приоритет. Реальная логика и интеграции выполняются после полного интерфейса.

## Согласованные предпочтения

- Современный деловой стиль: выразительные фотографии, чёткая сетка, красные акценты.
- Пользователь хочет оценивать конкретный визуальный результат, а не выбирать изображения только по текстовому описанию.
- Использовать качественные готовые компоненты из достоверных источников. Сначала проверять соответствие задаче и лицензию; затем адаптировать к бренду.
- Избегать мелких украшений, подчёркиваний при наведении, искусственных показателей и лишних элементов.
- При необходимости задавать вопросы пользователю **парами**.

## Что подготовлено

Просмотр: `http://127.0.0.1:4182/visual-direction/`.

1. Главная: исходный цветной логотип, рабочая фотография отеля, входы кандидата и работодателя, самостоятельный поиск вакансий, инструкция ниже первого экрана.
2. Кабинет: пример следующего шага, формы опыта, видеопрезентации, документов и пустого списка интервью.
3. Референсы и стиль: просмотренные страницы, применяемые решения, палитра, шрифт, готовые компоненты.
4. Переключение ширины компьютер/телефон. Это средство обсуждения композиции, а не готовые мобильные приложения.

Анкета, прогресс, этапы заполнения и статусы — демонстрационные. Поиск не подключён к базе. Сохранение отражает только состояние в памяти страницы; данные не отправляются и не сохраняются после перезагрузки. Формы не собирают реальные данные кандидатов. Видеоролика, записи камеры и входа ещё нет. Полный интерфейс не считается завершённым.

## Композиция публичной части

- Тёмная компактная шапка: белая версия предоставленного логотипа, навигация, языки, вход.
- Первый экран: фото сотрудников в отеле; текст занимает левую часть; люди остаются видимыми справа. Затемнение служит читаемости текста.
- Основное действие — «Создать анкету». Второе — «Я работодатель». Ни одно не обещает гарантированное трудоустройство.
- Рекламное место на компьютере отделено от вакансий и обозначено «Реклама». Сейчас показан пустой слот по ТЗ, а не выдуманное объявление.
- На телефоне слот убран из первого экрана как **предложение по размещению**; окончательный порядок рекламы требует согласования при полной адаптации.
- Ниже — самостоятельный поиск и категории, короткий путь кандидата, объяснение видеопрезентации. Раздел инструкции расположен ниже главного экрана по раннему пожеланию пользователя.
- Окно инструкции основано на кадре 16:9. Обучающий ролик пока не добавлен; камера не включается. Не выдавать этот макет за готовое видео.
- Новости, контакты, партнёрский раздел и юридические страницы остаются в карте продукта и будут оформлены дальше. Этот образец не заменяет всю главную из ТЗ.

## Рабочий интерфейс

- Графитовая навигация, светлый общий фон, белые поверхности форм и таблиц.
- Один приоритетный следующий шаг вместо ряда декоративных карточек со статистикой.
- В форме подпись находится над полем. Подсказки объясняют, что ввести. Ошибка в дальнейшем размещается рядом с полем и содержит способ исправления.
- Длинная анкета разбивается на тематические шаги; демонстрационные шесть разделов — UX-предложение, не обязательная структура ТЗ.
- Рабочая колонка и отдельная колонка следующего действия. На телефоне они идут последовательно.
- Цвет статуса сопровождается текстом и при необходимости значком: проверен, на проверке, не загружен. Цвет не является единственным носителем смысла.
- Пустое состояние интервью объясняет, когда появятся встречи. Пример «0 / 3» обозначает ограничение из ТЗ, а не реальные показатели.
- Собеседования, очередь модерации, профессиональные видеовопросы, доступ к документам и окончательный выбор отеля требуют отдельных экранов и точных правил по карте продукта.

## Сетка, формы и движение

- Ширина визуального образца: до 1376 px вместе с внутренними полями; основной контент — около 1280 px.
- Поля снаружи: 32 px на компьютере, 16–20 px на телефоне; интервалы основаны на 4/8 px.
- Кабинет: навигация 190–210 px, основной блок, вспомогательная колонка 228–260 px.
- Поля и основные кнопки: примерно 40–48 px высотой. На телефоне основной CTA во всю ширину.
- Умеренные радиусы: 6–8 px; большое округление оставлено только рамке режима просмотра телефона.
- Реакции элементов: 160 ms. Ссылки не получают подчёркивание при наведении. Фокус остаётся видимым.
- `prefers-reduced-motion` отключает переходы и плавную прокрутку. Видео не запускается автоматически.

## Материалы и компоненты

См. [источники компонентов](COMPONENT_SOURCES.md) и [источник фотографии](IMAGE_PROMPTS.md).

Оригинальные файлы логотипов не изменены. Использована локальная копия белой версии; SVG-окно показывает её значимую область без пустых полей. Чёрная версия с серой подложкой и свечением не используется на белой шапке, чтобы не исказить бренд.

Изображение отеля создано ИИ **только для визуального обсуждения**. Оно не показывает реальных кандидатов, сотрудников или партнёров. Перед коммерческим запуском предпочтительны разрешённые реальные фотографии в таком же рабочем контексте.

Для первого направления 3D не требуется. Blender MCP подключён для подходящих будущих задач; наличие инструмента не является основанием добавлять декоративные 3D-объекты.

## Сборка и следующий шаг

Исходники: `design/visual-direction-src`. Готовая страница: `design/product-map/visual-direction/index.html`. Пакеты и точные версии фиксирует `package-lock.json`.

Сборка: из каталога исходников выполнить `npm run build`. Статические материалы в `assets` сохраняются; итоговые JS/CSS лежат в `bundle`. Предупреждение Vite о пути шрифта объясняется тем, что файл обслуживается локальным сервером, а не импортируется в сборку. `use client` библиотек не используется в этой браузерной сборке.

Дизайн-направление подготовлено и показано в браузере. Автоматические тесты не запускались. Этап 2 ещё требует пользовательской оценки фотографий, палитры и композиции. После выбора направления — подробные главная, кабинет кандидата и запись презентации, затем остальные экраны.
