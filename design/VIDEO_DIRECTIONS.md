# Три направления видеоинструкции

Пользователь попросил новые варианты. Сравнение находится в prototypes/single/directions.html, исходный сайт сохраняет текущую инструкцию.

1. **Кинематографичный.** Тёмный раздел, большой фотокадр 16:9, центральная кнопка открытия. Подходит для ролика с ведущим. Для окончательного применения желательно заменить повторяющуюся фотографию уникальной обложкой настоящей инструкции.
2. **Светлый продукт.** Светлая поверхность, крупный макет анкеты и фирменное красное действие. Подходит для записи экрана с объяснением полей и видеоответов.
3. **Обучающий раздел.** Темы слева, компактный экран 16:9 справа. Темы ведут непосредственно к нужному учебному шагу. Подходит для обучения, к которому возвращаются несколько раз.

Все три используют общую интерактивную инструкцию. Настоящего видеоролика нет; это прямо указано под экраном. Варианты просмотрены на компьютере и телефоне. Выбор пользователя пока не получен.

Адрес: http://127.0.0.1:4173/single/directions.html?direction=1. Значения direction: 1, 2, 3.
