# Этап 2 — объяснение видеоанкеты

**Статус: описанный ниже первый вариант отклонён пользователем целиком.** Текущая версия использует video-v2.css: заголовок над единым крупным примером, фотография в полный рост и тёмная панель вопросов справа. Список шагов удалён. На телефоне панель идёт под изображением. Темы вопросов выбираются напрямую; пример текста ответа соответствует выбранному вопросу. Настоящий ролик пока не снят. Требуется обратная связь пользователя по новой композиции.

Раздел #how расположен ниже баннера и двух стартовых блоков. На компьютере слева показан кадр с кандидатом в полный рост и вопросом, справа — объяснение и три шага. На телефоне: заголовок → объяснение → пример → шаги → действие.

Кадр не обрезает голову и ноги. Кнопки под кадром переключают три демонстрационных вопроса. «Посмотреть пример ответа» открывает иллюстрацию с примером текста; воспроизведение настоящего видео не имитируется. «Как заполнить» открывает существующую пошаговую инструкцию. «Создать анкету» ведёт в демонстрационный сценарий профиля.

Основная логика: основные данные определяют вопросы; кандидат может переснять ответ; перед сохранением проверяет результат и выбирает видимость. Видео необязательно. В текущем прототипе запись и сохранение сервером ещё не реализованы.

Оформление: фон #fcfcfb, тёмная плашка вопроса #26302e, красное основное действие. Отдельные карточки для каждого шага не нужны; последовательность задана компактным списком. Подчёркивания при наведении отсутствуют, клавиатурный фокус сохранён.

Визуальный просмотр: компьютер и телефон шириной 390 CSS px. Для запуска требуется настоящий видеопример и согласие участника съёмки.
