Успешны инициализация MCP, получение списка **36 инструментов** и чтение `get_scene_info`. Результат в `connection-status.txt`. Blender был запущен скрыто с новой служебной сценой, существующие проектные `.blend` не открывались и не изменялись.

В текущем чате инструменты Blender ещё не появились: **после завершения текущей работы перезапустить Codex**, чтобы приложение загрузило новую конфигурацию. Это не требуется для просмотра визуального образца.

Если Blender был закрыт, открыть его и включить сервер в панели BlenderMCP → Start MCP Server. Запись MCP в Codex сама по себе не запускает мост внутри закрытого Blender. `start_bridge.py` использован для текущего служебного запуска.

## Для чего применять

Предметные сцены, содержательные фирменные иллюстрации, модели и анимации, когда они помогают конкретному экрану. На текущем этапе фотография гостиничной работы лучше объясняет продукт. Подключение MCP не означает обязательное использование 3D в дизайне.
