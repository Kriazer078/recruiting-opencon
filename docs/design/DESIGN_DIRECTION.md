# Design Direction — Open Consulting

Дата: 5 октября 2026. Статус: направление выбрано автономно по поручению пользователя; **визуальное утверждение пользователем ещё не получено**.

Учтены прежние решения пользователя (AGENTS.md): деловой стиль, выразительные реальные фото, чёткая сетка, красные акценты; без ИИ-изображений; HH/Enbek как ориентир понятности, а не шаблон.

## Три направления

### A. «Маршрут» — редакционный журнал коридора Казахстан → Турция

| | |
| --- | --- |
| Философия | Главная как длинный редакционный материал о пути из Шымкента в Анталью. Типографика главная, люди — портретные развороты |
| Hero | Огромный заголовок на всю ширину, линия маршрута «Шымкент → Анталья», один редакционный портрет |
| Типографика | Крупный кегль, контрастные размеры, длинные абзацы, нумерованные главы |
| Сетка | Асимметричные развороты 12 колонок, широкие поля |
| Изображения | Репортажные портреты и пейзажи двух стран |
| Движение | Прогресс чтения, спокойное появление глав |
| Кандидат | Портрет с цитатой, как в журнале |
| Вакансия | Колонка объявлений, «classifieds» |
| Навигация | Минимальная шапка + оглавление глав |
| Цвет | Тёплая бумага, чёрный, красный |
| Плюсы | Самобытно, зрелое, сильный нарратив |
| Риски | Слабая полезность маркетплейса, поиск и действия уходят вниз; много чтения для кандидатов с телефона; пейзажи превращают найм в туризм; плохо масштабируется на плотные кабинеты |

### B. «Ресепшен» — премиальный гостиничный сервис

| | |
| --- | --- |
| Философия | Сайт как лобби хорошего отеля: тишина, свет, консьерж-сервис |
| Hero | Полноэкранное фото отеля, короткий слоган, «консьерж»-форма |
| Типографика | Тонкие начертания, разрядка, много воздуха |
| Сетка | Широкие изображения, редкий текст |
| Изображения | Интерьеры, бассейны, курорты |
| Движение | Медленные кроссфейды, параллакс |
| Кандидат | Элегантная «визитка» гостя |
| Вакансия | Карточки как номера отеля с фото |
| Навигация | Прозрачная шапка поверх фото |
| Цвет | Песок, белый, золото |
| Плюсы | Премиально, приятно отелям |
| Риски | Похоже на бронирование/туризм; кандидат видит отпуск, а не работу; нет прав на фото отелей; спорит с выбранным пользователем деловым стилем; люди вторичны |

### C. «Знакомство до собеседования» — video-first отбор (выбрано)

| | |
| --- | --- |
| Философия | **Человек — на экране, условия — на бумаге.** Люди показаны в видеокадрах с полосой текста снизу (так устроены и запись презентации, и субтитры интервью). Всё фактическое — анкета, вакансия, документы — набрано как точный документ на тёплой каменной поверхности |
| Hero | Слева — предложение и два пути (переключатель роли). Справа — кадр видеопрезентации в формате 4:5 с полосой вопроса «2 из 6» и прогрессом 30 секунд. Переключение роли меняет **точку зрения на тот же кадр**: кандидат видит подсказки записи, отель — сводку анкеты |
| Типографика | Одна гарнитура IBM Plex Sans: полужатая ширина (`wdth` 82–85) для заголовков, обычная — для текста. Иерархия размером, шириной и весом, без декоративных шрифтов |
| Сетка | Строгие 12 колонок; главы в формате «левая колонка — номер и тема, правая — содержание» |
| Изображения | Реальные фото людей за работой в отеле, естественный свет, вертикальные кадры. Рамка медиа со срезанным под 45° нижним левым углом — форма «O» из логотипа |
| Движение | Смена вопросов в кадре (с паузой), заполнение слотов, переходы состояний. Без парения, параллакса и отскоков |
| Кандидат | Видеокадр + 4 фото (лицо, 3 в рост) + факты: профессии, опыт, языки по шкале ТЗ, готовность к проживанию и сменам, источник, светофор документов |
| Вакансия | «Лист условий»: профессия и зарплата на одной линии, место, затем строка условий (жильё, питание, график, язык), мета |
| Навигация | Светлая шапка, 7 пунктов меню из ТЗ, язык, вход, регистрация; на телефоне — полноэкранное меню с ролями первыми |
| Цвет | Тёплый камень (травертин) + почти чёрный + глубокий красный бренда для действий; амбра — только для строк перевода в кадре |
| Плюсы | Показывает реальное отличие продукта; масштабируется на каталог кандидатов, профиль, комнату интервью, кабинет; честно отражает механику ТЗ |
| Риски | Зависимость от реальных видео/фото → рамки готовы принять продакшн-съёмку; риск «соцсети» → без лайков, сердечек, автоплея звука; приватность → только помеченные примеры |

## Сравнение

| Критерий | A Маршрут | B Ресепшен | C Знакомство |
| --- | --- | --- | --- |
| Понятно за 5 секунд «найти работу / сотрудников» | Средне | Слабо (похоже на туризм) | Да |
| Видно отличие от job board | Через текст | Нет | Через сам интерфейс |
| Video-first | Косвенно | Нет | Центрально |
| Казахстан → Турция | Сильно | Слабо | Через время двух стран, языки, перевод |
| Hospitality | Средне | Сильно, но про гостей | Через работу людей в отеле |
| Масштабируемость на кабинеты | Слабо | Слабо | Сильно: те же кадр, лист условий, статусы |
| Соответствие прежним решениям пользователя | Частично | Противоречит | Да |
| Риск шаблонности | Редакционный тренд | Шаблон отельного сайта | Низкий, если держать дисциплину |

## Решение

Выбрано **C — «Знакомство до собеседования»**. Не самое безопасное (A/B проще держать красивыми), но единственное, где визуальная идея происходит прямо из механики продукта: запись с вопросом снизу, четыре фото, три слота, одно место, перевод на собеседовании.

Из A взято: сильная типографическая иерархия и главы-этапы. Из B: тёплая материальность и спокойствие. Остальное отклонено.

## Визуальный тезис (короткая версия для каждого нового экрана)

1. Люди — в рамке «O» (срез 45° внизу слева), текст о человеке — полосой снизу кадра.
2. Факты — на бумаге: линейки, таблицы, табличные цифры, без карточек ради карточек.
3. Красный — только действие или выбранное состояние. Амбра — только перевод в кадре.
4. Каждый блок показывает реальную механику ТЗ, а не обещание.
