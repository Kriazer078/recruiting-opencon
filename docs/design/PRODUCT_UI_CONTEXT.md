# Product UI Context — Open Consulting

Дата: 5 октября 2026. Постоянная память дизайна. Сверяться перед каждым новым экраном.

Источник требований: [ТЗ OC-TZ-JOBS-001 v1.1](../../TZ_OPEN_CONSULTING_V1_1.md) — **проект на утверждение**, не подписан заказчиком. Более поздние прямые указания пользователя имеют приоритет.

## 1. Что это за продукт

Платформа подбора персонала: **кандидаты из Казахстана → отели Турции**. Не доска объявлений: Open Consulting модерирует анкеты и компании, переводит на собеседованиях и сопровождает документы до выезда.

Рыночная проблема из ТЗ (раздел 2): кандидат обещает себя нескольким отелям, отель ждёт, человек уезжает к другому. Платформа закрывает это правилом **одного места**.

## 2. Аудитории

| Роль | Кто | Главная задача на сайте | Что важно |
| --- | --- | --- | --- |
| Работник (кандидат) | Молодые специалисты из Казахстана, чаще с телефона; RU/KZ | Найти работу в отеле Турции, создать анкету | Понятность шагов, доверие (нет обмана), язык |
| Работодатель (отель) | HR/управляющие отелей Турции; TR/EN/RU | Увидеть кандидата до собеседования, нанять надёжно | Видео, опыт, языки, гарантия «одного места», перевод |
| Оператор | Сотрудники Open Consulting | Модерация, перевод, документы | Плотные рабочие экраны (не на главной) |
| Партнёр | Агентства (ведут своих кандидатов) | Свой код, логотип, свои интервью и отчёты | Только свои данные |

## 3. Уникальные механики (источник визуального языка)

| Механика | Требование | Как проявляется в UI |
| --- | --- | --- |
| Видеопрезентация | FR-MED-02, Must: один ролик 20–40 с (цель 30), человек в рост и в лицо, **шесть вопросов по очереди внизу экрана** | Кадр с полосой вопроса снизу — фирменный «субтитровый» мотив |
| Четыре фото | FR-MED-01, Must: 1 лицо + 3 разных кадра в полный рост | Набор миниатюр «Лицо / В рост ×3» в карточке кандидата |
| Профессиональная видеоанкета | FR-MED-03, **Should** | Второй видеоблок; не заменяет презентацию |
| Три согласия — одно место | BR-01/02, Must | Счётчик «занято N из 3», недоступный 4-й слот с причиной, отдельное подтверждение выбора |
| Срок предложения | BR-04: 72 ч, напоминание за 12 ч | Таймер на предложении |
| Собеседование | BR-05/FR-INT-01: не раньше чем через 5 ч, смена режима не позже чем за 2 ч, комната на троих, запись 90 дней | Комната: отель, кандидат, переводчик; время двух стран |
| Режимы общения | Переводчик (Must), прямой английский (Must), субтитры RU↔TR (FR-INT-02, **Should**) | Полоса субтитров с пометкой «автоматический перевод может ошибаться» |
| Документы | FR-DOC-01: светофор «не собран / на проверке / готов»; файлы видит оператор; журнал открытий | Статус + текст, без файлов для отеля |
| Визовый трек | FR-VISA-01, **Should** | Пошаговый трек после взаимного подтверждения |
| Источник анкеты | FR-REG-03, FR-PAR-01 | Логотип Open Consulting или партнёра на карточке |
| Публичная часть | FR-UI-01/02/03, Must: меню без формы регистрации, отдельная реклама, новости без регистрации | Главная содержит новости и отдельный рекламный слот |

Часовые пояса: Казахстан с 1 марта 2024 — единый UTC+5, Турция — UTC+3. Разница 2 часа. Время двух сторон показывать явно (BR-05).

## 4. Правила доступа, влияющие на публичные экраны

- Гость видит меню, новости и рекламу без входа (приёмка, раздел 20).
- Анкеты кандидатов **не публичны**: отель видит только опубликованные анкеты по своим профессиям. На главной допустимы только **явно помеченные примеры**.
- Отель не видит номер паспорта и файлы справок (NFR-07, FR-DOC-01) — только статус пакета.
- Доступ гостя к списку вакансий — открытый вопрос ТЗ (раздел 8, п. 12). Публичный блок вакансий на главной — пример формата, а не решение о доступе.

## 5. Чего продукт не делает (нельзя обещать в интерфейсе)

- Не подаёт заявление в e-İzin, не выдаёт визы, не оказывает апостиль как услугу.
- Не гарантирует трудоустройство.
- Не оценивает внешность и личность по видео.
- Не публикует непроверенные анкеты и компании.

## 6. Must / Should на главной

Must: шапка (логотип, язык, вход, регистрация), меню из 7 пунктов, центральный блок с «Ищу работу» и «Я работодатель», отдельная реклама, новости, подвал с реквизитами, политикой и офертой.

Should-функции (субтитры, визовый трек, видеоанкета по профессии) показываются с пометкой «в первой коммерческой версии». Это решение интерфейса до уточнения состава пилота.

## 7. Неутверждённые значения

Цены (3 000 ₸ за месяц, пороги 3 вакансии / 5 наймов), тексты шести вопросов, реквизиты, контакты, юридические тексты, название на витрине — **не утверждены**. На главной они не показываются как факт; места для них помечены. Все числа правил вынесены в `src/homepage/data/rules.ts`.

## 8. Контент-правила

- Нет вымышленных показателей, отзывов, логотипов клиентов, рейтингов, наград.
- Демо-анкеты, демо-вакансии и демо-новости имеют видимую метку «Пример».
- Фото — реальные (Pexels), автор и лицензия в `media.ts` и в подвале. Люди на фото **не являются** кандидатами или сотрудниками партнёров. Перед запуском заменить собственной съёмкой.
- Изображения, созданные ИИ, не используются (решение пользователя).

## 9. Технический контекст

- Исходники: `design/visual-direction-src` (Vite 8, React 19). Новая главная — TypeScript в `src/homepage/`.
- Примитивы: `radix-ui` 1.6.7 (без стилей Radix Themes); иконки `lucide-react`.
- Шрифт: IBM Plex Sans variable (оси `wght` 100–700, `wdth` 75–100), локальный WOFF2-поднабор; казахские и турецкие буквы, ₸ и ₺ проверены.
- Просмотр: `http://127.0.0.1:4182/home/`. Прежний первый экран: `/home/first-screen.html`, направления: `/home/directions.html`.
