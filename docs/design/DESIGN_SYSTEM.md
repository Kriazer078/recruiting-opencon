# Design System — Open Consulting v1.0

Дата: 5 октября 2026. Источник истины в коде: `design/visual-direction-src/src/homepage/styles/tokens.css`. Документ описывает токены и компоненты, применённые на главной. **Визуальное направление ещё не утверждено пользователем** (см. [DESIGN_DECISIONS.md](./DESIGN_DECISIONS.md)): токены — рабочая основа, а не финальный бренд-бук.

## Цвет

Тёплый камень (травертин) + почти чёрный + глубокий красный бренда. Амбра — только строки перевода на тёмном видео.

## Типографика

IBM Plex Sans variable (WOFF2-поднабор 185 КБ, оси `wght` 100–700, `wdth` 75–100). Кириллица, казахские `ӘҒҚҢӨҰҮҺІ`, турецкие `İıĞğŞşÇçÖöÜü`, `₸ ₺ €` проверены. В шрифте нет `★` и `✕` — не использовать в тексте.

Без UPPERCASE-eyebrow. Цифры — `.t-num` (табличные). Русская вёрстка: `typo()` в `lib/typography.ts` привязывает короткие предлоги и тире; диапазоны — `range()` из `data/rules.ts` (без переноса после тире). Длина строки текста — до 62ch.

## Пространство и сетка

- Шаг 4 px: `--space-1…13` = 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128.
- Между главами: `--section-gap` 72 → 128; плотнее: `--section-gap-tight` 48 → 80.
- Контейнер 1280 + поля `--page-margin` 16 → 48; 12 колонок, `--grid-gap` 16 → 24.
- Брейкпоинты: 390 (база), 768, 1024, 1240 (полное меню), 1440.
- Шапка 72 px; цели касания ≥ 44 px.

## Форма и глубина

- Радиусы: 0 (секции, медиа), 2 px (чипы, статусы), 4 px (кнопки, поля), 6 px (диалоги, меню).
- **Срез 45° внизу слева** у медиа-рамок (`--chamfer-s/m/l` = 10/18/28 px) — форма «O» из логотипа. Только для людей и видео.
- Страница плоская; тень `--shadow-overlay` только у всплывающих слоёв.

## Движение

| Токен | Значение | Применение |
| --- | --- | --- |
| `--duration-instant` | 120 ms | наведение, нажатие |
| `--duration-quick` | 200 ms | переключатели, состояния |
| `--duration-moderate` | 320 ms | смена контента |
| `--duration-slow` | 600 ms | смена медиа |
| `--ease-standard` | `cubic-bezier(.2,0,0,1)` | всё входящее |
| `--ease-exit` | `cubic-bezier(.4,0,1,1)` | уход |

`prefers-reduced-motion` обнуляет длительности; автосмена вопросов в кадре отключается, остаётся ручной выбор. Контент никогда не скрыт до анимации.
