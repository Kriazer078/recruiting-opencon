# Единый вариант Open Consulting

Рабочие правила: ../../design/WORKING_PROMPT.md.

## Этап 1 — главный экран

Первое действие — поиск вакансий по должности и месту. Второе — создание анкеты. Видео добровольное, его демонстрация будет ниже главного экрана на следующем этапе.

Белая навигация и крупный фотобаннер, фирменный красный для поиска. Выбор роли, направления поиска и два содержательных блока: анкета соискателя и найм для компании. Основа композиции — Enbek и HeadHunter, подробно в ../../design/HERO_REFERENCE_UPDATE.md. Нет вымышленных счётчиков и подчёркиваний при наведении. Клавиатурный фокус сохранён.

Адрес при запущенном сервере из папки prototypes: http://127.0.0.1:4173/single/.

Главный экран адаптирован для компьютера и телефона. Общие переходы используют предыдущие демонстрационные экраны; их дизайн будет дорабатываться по этапам. Вакансии демонстрационные. Серверной авторизации, отправки анкет и записи камеры пока нет.

## Следующие этапы

1. Готово: демонстрация формата видеоанкеты, переключение трёх вопросов и объяснение заполнения. Настоящий ролик пока заменён явно обозначенной иллюстрацией и примером текста ответа.
2. Готово: список демонстрационных вакансий, фильтры, подробные обязанности и условия. Данные реальных компаний ещё нужны.
3. Создание анкеты, необязательное видео, просмотр и настройки видимости.
4. Путь работодателя.

Каждый этап: сценарий → композиция → реализация → визуальный просмотр на телефоне и компьютере.
