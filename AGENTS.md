# Контекст проекта Open Consulting

Перед планированием, оценкой, дизайном и разработкой прочитай [TZ_OPEN_CONSULTING_V1_1.md](./TZ_OPEN_CONSULTING_V1_1.md). Пользователь назначил это ТЗ основой дальнейшей работы 5 октября 2026 года. В файле есть анализ и полный перенос исходного DOCX.

- Документ OC-TZ-JOBS-001 версии 1.1 имеет статус проекта на утверждение. Не утверждай, что спорные требования уже подписаны заказчиком.
- Для текущей задачи учитывай первый контур Казахстан — отели Турции, четыре роли, обязательную короткую презентацию, проверку лица, документы, оплату, три активных одобрения и одно окончательное место.
- Must относится к пилоту, Should — к первой коммерческой версии. Сохраняй различия и отмечай противоречия приёмки с приоритетами.
- PROJECT_BRIEF.md и старые дизайн-файлы содержат ранние предположения. Не переносить из них автоматически необязательное видео, только веб или запуск всех отраслей в новую спецификацию.
- Визуальные рекомендации в разборе ТЗ — предложения. Сами по себе они не утверждают дизайн или стек.
- Более поздние прямые указания пользователя имеют приоритет. Различай документные требования, предположения и согласованные изменения.
- Исходные документы сохраняй без изменения. Файл ТЗ и данные кандидатов не публикуй как демонстрационный контент.
- Наличие ТЗ не является поручением реализовать все функции. Выполняй текущий запрос пользователя.

## Текущая последовательность работ

Пользователь 5 октября 2026 года выбрал сначала завершить полный интерфейс, затем подключать реальную логику. Ориентируйся на [план интерфейса](./design/UI_PLAN_CHECKLIST.md): карта сценариев и экранов, единое оформление, главная и опорные рабочие экраны, четыре кабинета, общие процессы, адаптация и связанный прототип. Правила переходов и состояния проектируются на этапе UX; сервер и интеграции выполняются после этапа интерфейса. Чек-лист отражает план, а не уже выполненные задачи.

Подготовленная карта этапа 1: [PRODUCT_MAP.md](./design/product-map/PRODUCT_MAP.md), интерактивный просмотр `design/product-map/index.html`. Исходный реестр — `screen-registry.json`, собирается через `build_map.py` и `map-template.html`. Версия 0.1 ещё не означает утверждения структуры.

## Визуальное направление и компоненты

**Последнее указание пользователя, 5 октября 2026:** прежний образец и три альтернативных направления отклонены. Работать маленькими шагами, сначала только главный первый экран. Основные референсы — HH и Enbek. Использовать реальные фотографии из интернета с проверенным источником и правами, без изображений, созданных ИИ. Не развивать отклонённые композиции как утверждённые. Текущий небольшой шаг описан в [HOME_SCREEN_BRIEF.md](./design/HOME_SCREEN_BRIEF.md); обсуждение композиции ещё открыто.

Пользователь затем выбрал HH основной опорой и уточнил: использовать полезные решения обоих референсов только когда они нужны Open Consulting; не собирать страницу из множества шаблонов. Текущий результат — один первый экран `http://127.0.0.1:4182/home/`, [HOME_SCREEN.md](./design/product-map/home/HOME_SCREEN.md). Визуальное оформление ещё не принято пользователем. Активный исходник — `design/visual-direction-src/src/home.jsx` и `home.css`; обычный `npm run build` теперь собирает `design/product-map/home`. Старые прототипы остаются историей.

Последнее замечание к первому экрану: шапка и нижний блок анкеты сливаются с обложкой. Запрошено сравнение оформления этих двух частей. [OPTIONS.md](./design/product-map/home/OPTIONS.md), `http://127.0.0.1:4182/home/?compare=1`, дополнительный файл стилей `home-options.css`. Три варианта не утверждены; рекомендации не считать выбором пользователя. Менять только обсуждаемые части, продолжать маленькими шагами.

Затем пользователь сказал, что вариант 2 «более-менее ок», но запросил ещё разные визуальные направления, самостоятельный дизайн, интерактивность и продуманные отношения элементов. Вариант 2 — ориентир, не окончательное утверждение. Новый результат: [DIRECTIONS.md](./design/product-map/home/DIRECTIONS.md), `http://127.0.0.1:4182/home/directions.html`: профессии, люди и карьера, видеоанкета. Объём — первые экраны. Новые исходники `directions.jsx`, `directions.css`; Vite имеет две точки входа. Роли меняют контент, профессия подставляется в поиск, примеры вопросов переключаются. Сервер, запись видео и реальные вакансии не реализованы. Следующий шаг — оценка этих направлений пользователем.

Пользователь выбрал современный деловой стиль: выразительные фото, чёткая сетка, красные акценты. Хочет сначала видеть результат и затем выбирать. Подготовленный образец этапа 2: [VISUAL_DIRECTION.md](./design/product-map/visual-direction/VISUAL_DIRECTION.md), просмотр `http://127.0.0.1:4182/visual-direction/`. Направление 0.1 ещё не утверждено. Исходники — `design/visual-direction-src`; сборка через `npm run build`.

Пользователь просит готовые качественные компоненты из достоверных источников. В образце реально установлены Radix Themes и Lucide; версии закреплены. [COMPONENT_SOURCES.md](./design/product-map/visual-direction/COMPONENT_SOURCES.md) различает использованные пакеты, референсы shadcn/ui и рассмотренные компоненты 21st.dev. Не заявлять, что сторонний компонент установлен, если изучались только его метаданные. Перед использованием проверять лицензию и смысл для продукта.

Используется IBM Plex Sans с проверенными казахскими и турецкими символами. Manrope исключён из единой системы из-за пропусков казахских букв. Старая демонстрационная фотография, созданная ИИ, отклонена пользователем и не должна использоваться в новых макетах. Логотип показан из копии исходника; оригиналы сохранять.

При необходимости пользователь просит задавать вопросы парами и отвечать кратко. Реальная логика, вход, видео и поиск ещё не реализованы; образец не заменяет полный интерфейс.

**Последнее указание пользователя:** три направления (включая A/B/C в DESIGN_DIRECTION.md) всё ещё похожи на AI-generated SaaS. Ждём: выбор основы и решение D17 (пункты меню «Кандидатам/Работодателям» в «Лицах»). Описание — [DESIGN_DIRECTION.md](./docs/design/DESIGN_DIRECTION.md), реализация и проверка — [CONCEPTS.md](./design/product-map/home/CONCEPTS.md). Главная v1 не менялась.

### Как запустить

```bash
cd design/visual-direction-src
npm ci
npm run check            # tsc typecheck + vite build → design/product-map/home
python -m http.server 4182 -d ../product-map   # просмотр: http://127.0.0.1:4182/home/ и /home/concepts.html
```

Фото на главной v1 загружаются с CDN Pexels (`src/homepage/data/media.ts`), нужен интернет. Первые экраны направлений 2.0 используют локальные копии фото; в облачном контейнере CDN Pexels заблокирован.
